- **Palette**: Warm cream (`#FAF7F2`), deep olive sage (`#545E44`), and dark espresso (`#181A15`) with antique gold accents (`#B08E55`).

- **Interactivity**: Filterable project showcases, interactive modal case studies, rotating circular seals, collapsible FAQs, and working contact form with confetti celebrations.

## 💻 Local Development Setup

### 1. Clone the repository
```bash
git clone https://github.com/priyanka-r-s/My-portfolio.git
cd "My-portfolio"
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open **[http://localhost:5173/](http://localhost:5173/)** in your browser.

### 4. Build for Production
```bash
npm run build
```
The optimized bundle will be created in the `dist/` directory, ready to deploy to **Vercel**, **Netlify**, or **GitHub Pages**.
